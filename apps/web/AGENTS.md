## App Structure

```text
apps/web/
|-- vite.config.ts
|-- public/    # Static assets
`-- src/
    |-- main.ts     # Vue app entrypoint
    |-- App.vue
    |-- views/      # App views
    |-- components/ # Reusable components
    `-- lib/        # Custom library files
```

## Tech Stack

- **Framework:** Vue 3
- **Language:** TypeScript 6
- **Styling:** Tailwind CSS 4
- **Linting:** Oxlint, Oxfmt
