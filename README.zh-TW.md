EvoSnake 是一款節奏明快的瀏覽器貪食蛇遊戲，加入了特殊蘋果、即時事件與排行榜壓力。它保留經典玩法的直覺性，但每一局都可能因為蘋果效果或事件而突然改變節奏。

## 功能特色

- **特殊蘋果**  
  每種蘋果都會影響玩法，包含加速、減速、穿身、縮短、額外得分，以及會懲罰失誤的腐爛蘋果。

- **即時事件**  
  連鎖獎勵、黃金熱潮、冰河時期等事件會在遊戲中途暫時改變規則，讓玩家必須即時判斷，而不是只靠固定路線。

- **多種難度**  
  不同難度會調整地圖尺寸、遊戲節奏與蘋果壓力，讓新手能上手，也讓熟練玩家有更高挑戰。

- **排行榜競爭**  
  分數會保存到排行榜中，讓每一局都有明確目標，也更有持續挑戰高分的動力。

- **支援桌機與手機操作**  
  EvoSnake 同時支援鍵盤與觸控操作，不論是在桌機還是行動裝置上都能遊玩。

## 設計理念

這款遊戲的核心目標是打造出**有趣**且**容易上手**的遊戲體驗。

基於這兩個方向，我保留經典貪食蛇的基本操作方式，避免讓玩家重新學習控制邏輯；同時，將創新重點放在遊戲機制本身，為原本單純的玩法加入更多變化。

在初期規劃時，我希望新機制能夠維持**直覺且容易理解**，因此曾設計出超過 10 種蘋果與多種遊戲事件。然而，在實作與調整過程中，我發現過多的元素會增加玩家的記憶負擔，反而影響遊戲的上手性。

因此，最終版本將內容收斂為 7 種蘋果與 3 個遊戲事件。這樣的設計能在維持玩法簡潔的同時，提供足夠的變化與新鮮感。
